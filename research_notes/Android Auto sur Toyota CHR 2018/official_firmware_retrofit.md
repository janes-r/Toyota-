## 1. Which official Touch 2 / Touch 2 with Go firmware exists in Europe, and is anything newer than VE3947 / 6.11.0WH documented?

### Takeaway
The Touch 2 with Go is made of two separately versioned parts. One is the display-audio ("DA") head unit, whose software is versioned like VE3947 / HE3947 / GE3947 / XE…, with device IDs 13TFDAEU-xxxx. The other is the "Go" navigation box (NA530), versioned 6.x.x, where the W/L/H suffix encodes the hardware variant. The only publicised "major" consumer software upgrade was the 6.x "Touch 2 with Go" refresh, announced in March 2016. For a 2018 C-HR, the combination VE3947 + 6.11.0WH appears in several sources as the expected or latest state. **I found no official or forum source documenting a DA version newer than VE3947, or a Go version newer than 6.11.0WH, for the C-HR.** Map releases (2018 v1 → 2019 v3 → later) are a separate product line and do not change these firmware numbers.

### Cited Findings
- **[OFFICIAL, UK]** On 1 March 2016 Toyota UK announced a refreshed "Toyota Touch 2 with Go", unveiled at the Geneva motor show. The package included three years of free map care and a **free software update for existing owners**, extendable by two years to match the five-year warranty — [Toyota UK media: Toyota Touch 2 with Go](https://media.toyota.co.uk/toyota-touch-2-with-go/) (also at [media.toyota.co.uk/?p=40073](https://media.toyota.co.uk/?p=40073)).
- **[OFFICIAL, UK]** The same upgrade is described as a redesigned, clearer menu, "10 new features", improved functionality on "over 30 items" and simpler connection to Toyota customer services — [Toyota UK Magazine: Toyota Touch2 with Go receives major software upgrade](https://mag.toyota.co.uk/toyota-touch2-with-go-receives-major-software-upgrade/).
- **[FORUM, UK]** Commenters on that article report mixed results after updating. Reported problems include USB music playback issues, slow map rotation and failed installs with a "consistency check" error. Some owners say they were charged about £99 for map updates they expected to be free — [comment pages of the same article, e.g. p.16](https://mag.toyota.co.uk/toyota-touch2-with-go-receives-major-software-upgrade/comment-page-16/), [p.20](https://mag.toyota.co.uk/toyota-touch2-with-go-receives-major-software-upgrade/comment-page-20/).
- **[FORUM, UK]** A C-HR owner on chrforums.uk posted exactly the user's combination, "My version is VE3947 Nav version is 6.11.0WH Map ID is 2018 v1", and asked where to get an update — [chrforums.uk: Touch 2 Software Update](https://www.chrforums.uk/threads/touch-2-software-update.2622/).
- **[FORUM, UK]** Toyota Owners Club: for a C-HR Excel, the Go navigation version "should be 6.11.0WH" — [Toyota Owners Club: 6.11 Touch and go update](https://www.toyotaownersclub.com/forums/topic/184462-611-touch-and-go-update/).
- **[Toyota dealer/service guide reproduced on manuals.plus, provenance unverified]** A document titled "DA & Ext. Box – How to Identify T2wG and Device ID – How to access the Service menu" lists DA software per model. It gives Camry as "GE3947 / VE3947 (depends which DA-unit type fitted)" and **C-HR as "VE3947"**, and states a "Minimum Required Software Version: 6.11.0" for an extension-box (Go) configuration — [manuals.plus PDF](https://manuals.plus/m/dbcc4aa12f48c082de538094557d54ae2edc6f1eca4b23e5e000fd166c5fc68c.pdf).
- **[FORUM / blog, attribution uncertain]** Search snippets report that Toyota's download page once listed "Toyota Touch 2 with Go – SW 6.11.0L" and "6.11.0H" for Touch 2 with Go Plus. These versions are consistent with the "6.11.0" baseline and the L/H/WH hardware suffixes. The snippet appeared alongside [blog.mbirth.uk: Toyota Touch 2 Firmware Update (21 Oct 2017)](https://blog.mbirth.uk/2017/10/21/toyota-touch-2-firmware-update.html) and the Polish thread below, so it could not be pinned to one URL.
- **[FORUM, PL/UK]** Practical notes from the same threads: one user found the files exceeded an 8 GB stick. A 16 GB USB 3.0 stick would not start the update, but a 32 GB USB 2.0 stick worked. Another user got a "key invalid" error at the activation-key prompt — [blog.mbirth.uk](https://blog.mbirth.uk/2017/10/21/toyota-touch-2-firmware-update.html); [forum.toyotaklub.org.pl topic 45711 p.135](https://forum.toyotaklub.org.pl/index.php?topic=45711.135).
- **[FORUM, PL]** The Toyota Klub Polska thread "Toyota Touch 2 – firmware update (Display Audio Software)" says a DA update was, "as far as I know, the only free radio software update released for these units". It was needed for the radio to reach the internet via a Bluetooth-paired phone. Another reply says that without the required module and antenna "there is no such update" — [forum.toyotaklub.org.pl topic 45711 p.195](https://forum.toyotaklub.org.pl/index.php?topic=45711.195); [p.165](https://www.forum.toyotaklub.org.pl/index.php?topic=45711.165).

"3947" therefore seems to be a common build number across DA hardware variants (GE/HE/VE/XE prefixes) — [Toyota Owners Club: Firmware upgrade (Yaris club) p.10](https://www.toyotaownersclub.com/forums/topic/189278-firmware-upgrade/page/10/); [Toyota Owners Club: Software Update (C-HR Club)](https://www.toyotaownersclub.com/forums/topic/216390-software-update/). The search tool could not tell which of these two threads holds which quote.
- **[OFFICIAL, UK]** Toyota UK says that "there are currently no software updates for Touch 2 (without Go)". - **Map vs firmware, for contrast.** "2018 v1" is a map release, announced as a map product — [toyotamaps.online: Toyota Touch 2018 update is out (2018 v1)](https://toyotamaps.online/blog/news/toyota-touch-2018-update-is-out-(2018-v1)). Toyota France hosts a quick guide for the Touch & Go 2 **map** release 2019 v3 — [toyota.fr QG_TouchGo2_2019v3.pdf](https://www.toyota.fr/content/dam/toyota/nmsc/france/my-toyota/carousel-v%C3%A9hicules/QG_TouchGo2_2019v3.pdf).
- **Over-the-air.** Toyota's OTA software updates (via DCM or Wi-Fi, with USB offline updates) are described only for the new-generation multimedia, for example the 2026 US C-HR BEV multimedia manual (US). Nothing similar was found for Touch 2 / Touch 2 with Go — [Toyota multimedia owner's manual C-HR BEV 2026 (US)](https://assets.sia.toyota.com/publications/en/omnav-s/OM42K44U/pdf/OM42K44U.pdf).

### Inferences
- The user's VE3947 (DA) + 6.11.0WH (Go/NA530) looks like the **final or current state** for a 2018 European C-HR. No source shows a later DA build for C-HR or a 6.12+/7.x Go build. "W" in 6.11.0WH most likely denotes the Go hardware variant fitted to C-HR (as L/H do for "with Go"/"Go Plus"), not a different software generation.
- Any further "update" the owner can buy for this unit is almost certainly a **map** update (2018 v1 → newer), delivered through MyToyota / Toolbox. A map update does not change VE3947 or 6.11.0WH and does not add features such as Android Auto.
- The Touch 2 with Go has **no OTA path**. Updates are USB-only (owner via MyToyota) or dealer-only (via TIS / service bulletins).

### Gaps
- No official Toyota changelog listing DA versions (e.g. VE39xx history) or Go versions after 6.11.0 could be retrieved. No official release dates for VE3947 or 6.11.0WH were found.
- The meaning of the user's device-ID suffix **"CA04"** (13TFDAEU-**CA04**) could not be confirmed. Sources only mention the DA02 / DA03 suffixes (see Q4). The manuals.plus guide probably lists it but could not be opened.
- The chrforums thread "CHR 1.8 Software Update 2020" ([link](https://www.chrforums.uk/threads/chr-1-8-software-update-2020.5655/)) may describe a 2020 software item for C-HR. It may well be an ECU/hybrid update rather than multimedia. Its content could not be read.

## 2. Toyota Europe "smartphone integration" (Apple CarPlay / Android Auto) programmes 2019–2021: models, production dates, head units, software update vs hardware swap

### Takeaway
In Europe, Toyota's official AA/CarPlay retrofit applied **only to cars already fitted with the 2019-generation "Multimedia 17" (MM17) Toyota Touch head unit**. These were mainly Corolla (E210) built from January 2019 and RAV4 (XA50) MY19/MY20, and in some markets Camry/Prius on MM17. The retrofit was a **dealer-installed, paid software activation**, not a hardware swap, available from around May–June 2020. From MY2020 onward, Toyota fitted the newer "MM19" system with AA/CarPlay as standard. This includes the **facelift C-HR launched in Europe in October 2019**. Older Touch 2 / Touch 2 with Go units (the 2016–2019 C-HR, Auris, Yaris, pre-2019 Prius, etc.) were excluded.

### Cited Findings
- **[OFFICIAL, UK]** "Owners of Corolla and RAV4 models produced since 2019 now have the possibility of an upgrade to their Toyota Touch 2 multimedia system" to include Apple CarPlay and Android Auto. The work is done by appointment at the local Toyota centre, with Toyota recommending it be done during a scheduled service. "Depending on vehicle and specification, Toyota has installed its enhanced multimedia system as standard equipment since the 2020 model year." — [Toyota UK Magazine: Toyota Apple CarPlay and Android Auto upgrade](https://mag.toyota.co.uk/toyota-apple-carplay-and-android-auto-upgrade).
- **[OFFICIAL, UK staff replies]** Eligibility is checked per VIN or registration. Toyota UK stated "not all vehicles are compatible due to hardware and software compatibility". The RAV4 upgrade is "available on MY19 and MY20 RAV4" (one reply excludes the Icon grade). Some 2019 RAV4s, for example a Japanese import, were told "it is not possible to retrofit Apple CarPlay to your RAV4 as the multimedia system is not compatible". The connection is **wired** — [comment pages 2](https://mag.toyota.co.uk/toyota-apple-carplay-and-android-auto-upgrade/comment-page-2/), [8](https://mag.toyota.co.uk/toyota-apple-carplay-and-android-auto-upgrade/comment-page-8), [13](https://mag.toyota.co.uk/toyota-apple-carplay-and-android-auto-upgrade/comment-page-13), [17](https://mag.toyota.co.uk/toyota-apple-carplay-and-android-auto-upgrade/comment-page-17).
- **[OFFICIAL, UK staff replies + FORUM price reports]** Cost was described as available "for a small fee" and set by each centre. Owner-reported quotes ranged from about £50 alongside a service, to £99 for CarPlay plus a mandatory £190 map update (£289 total) on a 2019 Corolla Estate, to £150, about £250 and about £375 (software + map). One owner said the dealer required a £230 sat-nav update first. Toyota warned that self-installation (e.g. via OBD) "may damage your multimedia system and invalidate your warranty" — [comment pages 22](https://mag.toyota.co.uk/toyota-apple-carplay-and-android-auto-upgrade/comment-page-22), [49](https://mag.toyota.co.uk/toyota-apple-carplay-and-android-auto-upgrade/comment-page-49/), [51](https://mag.toyota.co.uk/toyota-apple-carplay-and-android-auto-upgrade/comment-page-51/), [54](https://mag.toyota.co.uk/toyota-apple-carplay-and-android-auto-upgrade/comment-page-54/).
- **[OFFICIAL, UK staff reply, older]** For the Prius+ (Prius Plus), Apple CarPlay "can be retrofitted by your local Toyota Centre at a cost of £50 with a service or £120 as a stand-alone fit" — [Toyota UK Magazine comment pages (search snippet)](https://mag.toyota.co.uk/toyota-apple-carplay-and-android-auto-upgrade/comment-page-3). (This is unexpected for a Prius+ and is noted as reported. It could not be cross-checked.)
- **[OFFICIAL, France]** Toyota France's retrofit page says vehicles with a Toyota Touch device "**Multimedia 17, 17MM, CY17, 17CY**" can get the update, lists Corolla with and without navigation, and tells owners to contact their dealer — [toyota.fr: Retrofit (My Toyota)](https://www.toyota.fr/service-and-accessories/my-toyota/retrofit); see also [toyota.fr: Mise à jour système multimédia](https://www.toyota.fr/support/mise-a-jour-systeme-multimedia).
- **[OFFICIAL, France]** A Toyota France FAQ says that **from June 2020** dealers could install Apple CarPlay / Android Auto on **Corolla Hybrid and Corolla Touring Sports built from January 2019** — [toyota.fr: FAQ multimédia Ma Toyota](https://www.toyota.fr/informations/faq/multimedia-ma-toyota).
- **[FORUM, UK]** "New 2019 Camry, Corolla, Prius & Rav launched this year with the newer **MM17**, of these the Corolla & Rav owners will be able to purchase an upgrade to **MM19** from May 2020". Also: "2020 Corolla, Rav4 & New facelift C-HR will come with MM19 which includes Android auto / Apple carplay from factory" — [Toyota Owners Club: Android auto retrofit (C-HR Club)](https://www.toyotaownersclub.com/forums/topic/204281-android-auto-retrofit/); [Toyota Owners Club: 2019 android auto or apple car play](https://www.toyotaownersclub.com/forums/topic/227387-2019-android-auto-or-apple-car-play/).

HiLux was excluded because its infotainment system "is not compatible". The facelifted C-HR had AA/CarPlay from launch — [Toyota Australia news: Toyota introduces Apple CarPlay/Android Auto on select vehicles](https://www.toyota.com.au/discover/news/toyota-introduces-apple-carplay-android-auto-on-select-vehicles); [GoAuto, 1 Nov 2019](https://goauto.com.au/news/toyota/toyota-offers-apple-carplay-android-auto-retrofit/2019-11-01/80597.html); [CarAdvice: CarPlay retrofit $199](https://www.caradvice.com.au/news/toyota-apple-carplay-retrofit/); [Toyota Australia: Hybrid powertrain headlines upgrade for Toyota C-HR](https://www.toyota.com.au/news/hybrid-powertrain-headlines-upgrade-for-toyota-chr).

### Inferences
- The European retrofit was effectively **"MM17 → MM19-level software activation"** on hardware that was already AA/CarPlay-capable. It was not a programme for Touch 2 / Touch 2 with Go (the Panasonic-built DA unit plus separate Go nav box of the 2016–2019 C-HR).
- Model coverage in Europe, from the evidence: **Corolla E210 (from Jan 2019 build) and RAV4 XA50 (MY19/MY20)** are clearly eligible (UK and FR official). Camry and Prius on MM17 are probable (AU official; EU forum claim). **C-HR pre-facelift, Yaris (XP130), Aygo (AB40), Auris (E180), Prius+ (varies), Hilux and Proace** are not covered by any EU retrofit source found. Aygo, Yaris and Proace had their own Toyota Touch / x-touch / ProTouch systems with separate smartphone-mirroring histories that were not researched here.
- AA/CarPlay as factory standard on the **facelift C-HR in Europe** dates from the October 2019 facelift launch (MY2020 build), matching forum claims of a September 2019 production change-over.

### Gaps
- No **newsroom.toyota.eu** (Toyota Motor Europe) pan-European press release about the retrofit could be found. Germany, the Netherlands and Poland official pages were not retrieved. Searches in German returned only UK sources.
- Exact European retrofit start date (May vs June 2020), official list price, and whether some markets did it free could not be verified (FR says June 2020, a UK forum says May 2020).
- Whether Camry, Prius and Proace were included in Europe is not confirmed by any official EU source.

## 3. Was any 2018 (pre-facelift) C-HR eligible anywhere in Europe? Toyota statements on hardware limits

### Takeaway
**No.** Every Toyota UK staff answer found states that the pre-facelift (2016–2019) C-HR's multimedia system is **incompatible** with the Apple CarPlay / Android Auto software and that **no retrofit is or will be available**. No European market page lists the C-HR as eligible. Owner forums agree that the Touch 2 (gen 2) unit "does not support AA or AC" and "can't be officially updated".

### Cited Findings
- **[OFFICIAL, UK staff reply]** "The multimedia system in the C-HR is not compatible with the Apple CarPlay/Android Auto software so a retrofit is not possible." — [Toyota UK Magazine comments p.22](https://mag.toyota.co.uk/toyota-apple-carplay-and-android-auto-upgrade/comment-page-22) (same wording on several pages, e.g. [p.49](https://mag.toyota.co.uk/toyota-apple-carplay-and-android-auto-upgrade/comment-page-49/)).
- **[OFFICIAL, UK staff reply]** "The multimedia system in previous generations of the C-HR is incompatible with the Apple CarPlay/Android Auto software so retrofit will not be available" / "there will be no Apple CarPlay/Android Auto retrofit for the C-HR as the multimedia system is incompatible with the software" — [Toyota UK Magazine comments p.49](https://mag.toyota.co.uk/toyota-apple-carplay-and-android-auto-upgrade/comment-page-49/); [p.62](https://mag.toyota.co.uk/toyota-apple-carplay-and-android-auto-upgrade/comment-page-62/).
- **[OFFICIAL, UK staff reply]** "We have no news on an update being available for the C-HR at the moment." Toyota also notes that the current-generation C-HR Hybrid "now features Apple CarPlay and Android Auto" and points owners to the VIN-based online owner's manual to check their car's equipment — [Toyota UK Magazine comments p.22](https://mag.toyota.co.uk/toyota-apple-carplay-and-android-auto-upgrade/comment-page-22); [p.31](https://mag.toyota.co.uk/toyota-apple-carplay-and-android-auto-upgrade/comment-page-31/).
- **[OFFICIAL, UK staff reply]** Some late-2019 C-HRs "should come equipped with Apple CarPlay and Android Auto as standard" (wired), to be confirmed via the VIN — [Toyota UK Magazine comments p.22](https://mag.toyota.co.uk/toyota-apple-carplay-and-android-auto-upgrade/comment-page-22).
- **[FORUM, UK]** "The 2019 C-HR had older Touch 2 unit, which can't be officially updated". "Earlier Touch 2 head units aren't compatible". The October 2019-onwards facelift C-HR has AA/CarPlay fitted — [Toyota Owners Club: Android auto retrofit](https://www.toyotaownersclub.com/forums/topic/204281-android-auto-retrofit/); [Toyota Owners Club: 2019 android auto or apple car play](https://www.toyotaownersclub.com/forums/topic/227387-2019-android-auto-or-apple-car-play/); [Toyota Owners Club: Android auto (C-HR)](https://www.toyotaownersclub.com/forums/topic/230350-android-auto/).
- **[FORUM, UK]** "09/2019 was the change over date between the gen2 and gen3 touch systems for the C-HR". About a late car: "that's very late touch 2 gen 2 – this generation does not support AA or AC" — Toyota Owners Club C-HR Club, quoted in search snippets. The thread is likely [topic 216390](https://www.toyotaownersclub.com/forums/topic/216390-software-update/) or [topic 205355 "Touch2 – touch2 with go"](https://www.toyotaownersclub.com/forums/topic/205355-touch2-touch2-with-go/). The exact thread URL could not be confirmed.
- **[FORUM, UK]** Owners asking about AA on the Touch 2 with Go are pointed to third-party add-on boxes or aftermarket units, not a Toyota solution — [chrforums.uk: Android Auto Add On?](https://www.chrforums.uk/threads/android-auto-add-on.3334/); [chrforums.uk: Touch2 with Go Replacement options?](https://www.chrforums.uk/threads/touch2-with-go-replacement-options.4528/).

### Inferences
- A C-HR **first registered 13 July 2018** was built well before the September/October 2019 change-over. It carries the Touch 2 (gen 2) DA unit (VE3947) plus the NA530 Go box and is **not eligible for any official Toyota Android Auto update or retrofit in Europe**. Toyota's own wording, "multimedia system … incompatible", amounts to a hardware/platform limitation statement, not a pending-software statement.
- The only "Toyota" route to factory AA on this car would be a **head-unit hardware change** (see Q6), which Toyota did not offer as a programme.

### Gaps
- No **French, German, Dutch or Polish** Toyota customer-service statement specifically about the 2018 C-HR was found. Only Toyota UK staff replies were found. Toyota France's retrofit page lists MM17 units only, which implicitly excludes the C-HR's Touch 2.
- No official Toyota document explicitly using the words "hardware limitation" was found. "Incompatible multimedia system" is the closest official phrasing.

## 4. Technical Service Bulletins / campaigns for Touch 2 software (C-HR), with version numbers

### Takeaway
The best-documented European bulletin is **BE-0003T-0116** (2016). It is a Touch 2 / Touch 2 with Go DA software update fixing auto-reboot and freeze problems and Bluetooth becoming unusable, with packages keyed to device IDs **13TFDAEU-DA02 / DA03**. The file is retrieved by dealers (or TIS subscribers) by VIN and bulletin number and installed via USB. No C-HR-specific multimedia TSB with a newer version number was found.

### Cited Findings
- **[FORUM quoting Toyota bulletin]** Bulletin **BE-0003T-0116**: "Software update including major bug fixes and patch for '00000000' software version". Per forum users, "The package works on hardware IDs '13TFDAEU-DA02' and '13TFDAEU-DA03'" — search snippets from [blog.mbirth.uk](https://blog.mbirth.uk/2017/10/21/toyota-touch-2-firmware-update.html) and [forum.toyotaklub.org.pl topic 45711](https://www.forum.toyotaklub.org.pl/index.php?topic=45711.165). Which of the two holds which quote is uncertain.
- **[FORUM]** BE-0003T-0116 applies to Touch 2 units built before the countermeasure software. Listed symptoms include the unit freezing then rebooting ("Display Audio-unit restarts by itself") and Bluetooth becoming unusable. The file is obtained via Toyota's technical portal by entering the VIN and bulletin ID, copied to USB and installed with the engine running — [Toyota Owners Club: Touch 2 freezing then rebooting](https://www.toyotaownersclub.com/forums/topic/181735-touch-2-freezing-then-rebooting/); [page 2](https://www.toyotaownersclub.com/forums/topic/181735-touch-2-freezing-then-rebooting/page/2/).
- **[FORUM]** Bluetooth issues on Touch 2 with Go include a reboot while Bluetooth auto-reconnects after a link loss. Workarounds include resetting Bluetooth through the service menu. The Touch 2 with Go has **separate software updates for the DA unit and the Go navigation unit**, and both may need updating — [Toyota Owners Club: Touch 2 system – bluetooth problem](https://www.toyotaownersclub.com/forums/topic/196318-touch-2-system-bluetooth-problem/).
- **[Toyota repair manual, third-party host]** The Toyota Touch 2 repair manual has an "Auto-reboot related issues" section (p.65) with a service procedure — [ManualsLib: Toyota Touch 2 repair manual](https://www.manualslib.com/manual/1813654/Toyota-Touch-2.html).

### Inferences
- The user's device ID **13TFDAEU-CA04** does not match the DA02/DA03 IDs targeted by BE-0003T-0116. This is consistent with the C-HR (launched late 2016) using a later DA hardware revision that already shipped with the countermeasure software. The inference is weak and unconfirmed.
- If the owner's unit shows reboot or Bluetooth faults, the dealer should check TIS for any bulletin matching "13TFDAEU-CA04". None was found publicly.

### Gaps

## 7. How the owner can check for and install official updates (USB / MyToyota / Toolbox)

### Takeaway
1. **Check the versions:** Setup → General → System information on the Touch 2 with Go.
2. **Look for updates:** create a MyToyota account, register the car and its "Toyota Touch 2 with Go" unit (choosing the correct High/Low variant), and check the e-Store's **Software Updates** section (firmware, no activation code) and **Map Updates** section (maps, 16-digit activation key, often paid after the free period).
3. **Install:** download via the Windows-only Toyota (MapUpdate) Toolbox to an empty FAT32 USB stick of 8 GB or more (some users needed larger, USB 2.0), then install in the car while it is stationary.

DA bug-fix bulletins are dealer-only, via TIS.

### Cited Findings
- **[OFFICIAL, UK]** Touch 2 with Go owners "can visit the e-Store via MyToyota to download the latest map update" using a USB stick. Owners of older Touch & Go systems are told to contact their local dealer — [toyota.co.uk: How do I perform a map update?](https://www.toyota.co.uk/owners/connectivity/map-updates).
- **[OFFICIAL, UK]** The USB stick must be **FAT32**, **8 GB or greater**, and **empty**. Software updates are under "Software Updates" in the MyToyota e-Store and need no 16-digit code (map updates do) — [Toyota UK Magazine: Toyota Touch 2 – how to update maps and software](https://mag.toyota.co.uk/toyota-touch-2-how-to-update-your-maps-and-software/).
- **[OFFICIAL, UK staff replies]** The steps are: create a My Toyota profile, register the vehicle and Touch 2 with Go system, claim a free update key, download to USB and insert it in the car. Select "Toyota Touch 2 with Go (High)" rather than Low where appropriate. The Toolbox "requires a Windows PC", because Mac is not supported. The vehicle must be stationary during the update. Check the system information screen (or "more info") for the software version. If "Update content consistency check failed" appears, reformat the stick to FAT32 — [comment pages 1](https://mag.toyota.co.uk/toyota-touch-2-how-to-update-your-maps-and-software/comment-page-1), [3](https://mag.toyota.co.uk/toyota-touch-2-how-to-update-your-maps-and-software/comment-page-3/), [9](https://mag.toyota.co.uk/toyota-touch-2-how-to-update-your-maps-and-software/comment-page-9), [10](https://mag.toyota.co.uk/toyota-touch-2-how-to-update-your-maps-and-software/comment-page-10), [11](https://mag.toyota.co.uk/toyota-touch-2-how-to-update-your-maps-and-software/comment-page-11/).
- **[FORUM, UK]** Users report paying over £100 for map updates, and Toolbox updates crashing with "insufficient storage" — [Toyota UK Magazine comments p.13](https://mag.toyota.co.uk/toyota-touch-2-how-to-update-your-maps-and-software/comment-page-13), [p.16](https://mag.toyota.co.uk/toyota-touch-2-how-to-update-your-maps-and-software/comment-page-16).
- **[Toyota service guide, third-party host]** The device ID and DA/Go versions are found via Setup → General → System information. The service menu is also described — [manuals.plus PDF](https://manuals.plus/m/dbcc4aa12f48c082de538094557d54ae2edc6f1eca4b23e5e000fd166c5fc68c.pdf); [ManualsLib repair manual](https://www.manualslib.com/manual/1813654/Toyota-Touch-2.html).
- **[OFFICIAL, France]** Toyota France has a dedicated "mise à jour système multimédia" support page and an FAQ — [toyota.fr/support/mise-a-jour-systeme-multimedia](https://www.toyota.fr/support/mise-a-jour-systeme-multimedia); [toyota.fr/informations/faq/multimedia-ma-toyota](https://www.toyota.fr/informations/faq/multimedia-ma-toyota).

### Inferences
- For this owner, the realistic official action is a **map update** (2018 v1 → latest available). The owner can also check the MyToyota "Software Updates" tab. If it offers nothing above VE3947 / 6.11.0WH, the unit is at its final firmware. Neither action will add Android Auto.

### Gaps
- The current (2025–2026) state of the European MyToyota e-Store for Touch 2 with Go could not be checked: whether it is still live, whether "Toyota MapUpdate Toolbox" is still distributed, and the latest map release offered. The exact name "Toyota MapUpdate Toolbox" was not confirmed by a retrievable source; Toyota UK calls it the "Toyota Toolbox". Its relation to NNG/naviextras was not documented in the sources found.
